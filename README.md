# channel-intro

배움의 달인 채널 소개 페이지. 그록봇 + Cursor 클라우드 에이전트 튜토리얼 실습용 저장소입니다.

한 페이지 정적 사이트입니다. 빌드 단계, 서버, 외부 API는 없습니다. 브라우저에서 `index.html`을 열면 됩니다.

로컬 서버로 보려면:

```bash
python3 -m http.server 4173
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.
